Optional OSS add-ons
---------------------
Each of the eight optional add-ons below resolves one of three ways (see
helm/datapond/templates/_addons.tpl for the rule):

  - an explicit `true` in your values (or `--set <component>.enabled=true`) runs it
  - an explicit `false` removes it, even if this namespace is already running it
  - leaving it unset (the chart default) keeps it ON, preserved, only if this
    namespace was already running it -- otherwise it stays OFF

This is what lets a fresh install stay lean while an existing deployment that never
chose an explicit value keeps exactly what it is running, unaffected by an upgrade.

To turn any one of them off explicitly -- including one this release reports as
"preserved" above -- add the matching flag and upgrade:

  --set airflow.enabled=false
  --set spark.enabled=false
  --set polaris.enabled=false
  --set risingwave.enabled=false
  --set openmetadata.enabled=false
  --set jupyter.enabled=false
  --set mlflow.enabled=false
  --set trino.enabled=false

To turn one on explicitly, use the same flag with `=true` instead.
